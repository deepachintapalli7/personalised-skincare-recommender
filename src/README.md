# Source code

Reusable Python modules for the skincare recommendation project will live here.

Planned modules:

- `data_loader.py` — load and validate permitted local dataset files
- `preprocessing.py` — clean product and ingredient fields
- `features.py` — build product feature representations
- `recommender.py` — generate content-based recommendations
- `evaluation.py` — calculate ranking and coverage metrics

Modules will be added after the corresponding workflow is implemented and tested.
