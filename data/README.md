# Data

Raw datasets are stored locally and are intentionally not committed to this public repository to avoid large files and licensing or redistribution issues.

When data is added locally, keep the original source and download date documented. The initial planned source is the Sephora product dataset, with `product_info.csv` as the first file to inspect.

Do not upload personal data, credentials, or restricted data. Any future processed sample committed here should be small, documented, and permitted for redistribution.
